# Starways Super Express

Static course website for Hamster Hub: Starways Super Express,
26 October–27 November 2026. Three milestones cover an MVP, market analysis,
AI-assisted software engineering, presentation, startup development, user testing
and feedback, and a final presentation.

## Pages

- `index.html` — course, three milestones, community project videos and signup
- `parents.html` — information for parents
- `curriculum.html` — full curriculum details
- `credits.html` — illustration, project and font credits

## Local preview

Run `python -m http.server 8816` from this folder, then open `http://localhost:8816`.
No build step or package installation is required. All local URLs are relative,
including assets, so the site can be served from a GitHub Pages project path.

Display/body fonts are self-hosted; their SIL OFL notices are included with the assets.
Original community videos are linked with creator credits; these are community
examples, not claimed outcomes of this course cohort. Generated illustrations
are conceptual artwork. Internal video, audio, transcripts and source notes
are excluded from this repository.

This source contains the current production files and optimized assets only.
Signup links contact Hamster Hub through LINE; the website does not process payments.
